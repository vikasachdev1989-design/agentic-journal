1 · Data → KPI map business view

Each uploaded file becomes one clean table. KPIs are calculated from those tables, and each dashboard shows a set of KPIs. Hover or tab to any box to see everything it feeds and everything it depends on.

2 · How it runs technical view

A scheduled job picks up new uploads every morning. Files that fail checks are held back and flagged, so a bad file never reaches a dashboard. Files that pass are cleaned, loaded, and the dashboards refresh.
